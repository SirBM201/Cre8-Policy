How Cre8 Studio uses the YouTube API

This interactive page explains exactly how Cre8 Studio connects to YouTube using Google OAuth, how video uploads are triggered, and how we protect YouTube user data. Use this page to record your audit screenshots: hover over the “i” icons to see detailed notes for reviewers.

When the creator clicks Connect YouTube, we redirect them to https://accounts.google.com/o/oauth2/v2/auth. All consent screens, passwords, and 2FA steps are handled by Google.

  • Cre8 Studio does not create channels or modify existing videos.
  • Each connection is tied to a single Cre8 Studio user account (creator-controlled).
  • Tokens are stored securely on the server and can be revoked at any time.

Once the user clicks Allow, Google issues an authorization code which our backend exchanges for tokens using oauth2/v4/token. Tokens are stored encrypted and are used only to perform the user-initiated actions described on this page.

When the user clicks Upload to YouTube, our backend calls youtube.videos.insert using the authenticated user’s access token. The upload is performed only to that user’s own channel; we do not upload to any channel we control.

  • All uploads originate from video files already stored in Cre8 Studio or provided by the creator.
  • Creators can cancel or reschedule posts before the upload call is made.
  • No Content ID, analytics, or advertising APIs are used in this workflow.

Data protection & retention
How Cre8 Studio handles YouTube data i
Minimal data, encrypted tokens, no resale or secondary use
For screenshot: Data handling
  • Access tokens and refresh tokens are stored server-side in an encrypted database with restricted access.
  • We store only:
    • Connected channel ID and display name for account linking.
    • Upload jobs with YouTube video IDs and timestamps.
    • User-supplied video metadata (titles, descriptions, tags).
  • We do not:
    • Store or process YouTube Analytics or Reporting data.
    • Use YouTube data for ad targeting, resale, or market research.
    • Mix YouTube data with data from other platforms to build external profiles.

Data retention is limited to what is necessary to support the creator’s account and comply with our legal obligations. If a user disconnects YouTube, we stop using their tokens and mark related jobs as inactive.

When the creator clicks Disconnect YouTube, we delete the stored tokens and cancel any future upload jobs for that channel. Google’s own “Security → Third-party access” page also allows users to revoke our access instantly.

  • Disconnecting is always available from within the Cre8 Studio UI.
  • We provide clear messaging that revocation stops all future uploads.
  • Users can re-connect later by repeating the Google OAuth flow.
