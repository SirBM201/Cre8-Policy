Last updated: 28 November 2025

1. Purpose of the Service

Cre8 Studio Posting Engine provides a secure posting assistant for creators who wish to authorize automatic publishing of their own media content to TikTok and other platforms using official API integrations. We only perform actions permitted under the TikTok Developer Terms, including uploading content, scheduling posts, and retrieving basic posting information.

3. API Compliance & Authorized Actions Only

The Service acts only upon explicit user authorization and performs permitted actions such as:

  • Posting user content through official TikTok API endpoints
  • Retrieving post-status responses allowed by the API
  • Handling access tokens for session authentication

The Service does not:

  • Collect unauthorized TikTok user data
  • Scrape TikTok
  • Bypass TikTok security or permissions
  • Modify, distort, or intercept TikTok internal data

4. Data Use & Security

Any API tokens, identifiers, or posting credentials are handled only to perform Service functions requested by the user. Such credentials are not shared, resold, or used to access accounts outside the user’s instruction.

We use HTTPS and standard GitHub Pages hosting for policy file access. No external data transfer, third-party profiling, advertisement networks, or personal data sale is performed.
